# Koelen (optioneel)

Open [Instellingen - Koelen](./configuratie-koelen.html).

1. Kies `select.openamber_koelmodus`.
2. Gebruik `number.openamber_koelen_setpoint` bij intern setpoint.
3. Gebruik `number.openamber_handmatig_setpoint_cv_aanvoertemperatuur` bij extern setpoint.
4. Gebruik dauwpuntbeveiliging in Home Assistant voor veilige aansturing.

Volgende stap: [Energiebeheer (optioneel)](./smartgrid.html).
